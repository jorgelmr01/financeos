# FinanceOS — App Store Screenshot Shot List

Capture each screen twice (once in English, once in Spanish), on both required sizes:
- **6.9"** — 1290 × 2796 px (e.g. iPhone 16 Pro Max)
- **6.5"** — 1242 × 2688 px (e.g. iPhone 14 Pro Max)

Tip: before capturing, tap **"Load sample data"** on the welcome screen so every screen shows rich, realistic content. Turn on **Privacy Mode** only for the privacy shot (shot 6) — everywhere else amounts should be visible. Use the dark "ledger after midnight" theme for shots 1–5 (it's the default and most distinctive); shot 6 can show the lock screen.

Order matters: App Store shows the first 2–3 screenshots most prominently.

---

## 1. Today dashboard
**What to capture:** The Today page scrolled to the top — Financial Health score, "needs attention" feed, net worth with daily change, asset composition, upcoming deposits.

| | Caption |
|---|---|
| EN | Your money at a glance |
| ES | Tus finanzas de un vistazo |

*Why first: it sells the whole promise in one screen — one score, one feed, everything that matters.*

## 2. Accounts
**What to capture:** The Accounts page showing two or three accounts with APY badges and the auto-interest schedule visible (e.g. a savings account with "monthly" payout and the live accrual line).

| | Caption |
|---|---|
| EN | Interest calculated automatically |
| ES | Intereses calculados automáticamente |

## 3. Portfolio
**What to capture:** The Portfolio page with allocation chart and return-by-position chart, after tapping "Update prices" so live quotes are shown. Pick sample data with a mix of green/red positions.

| | Caption |
|---|---|
| EN | Live prices, real returns |
| ES | Precios en vivo, rendimientos reales |

## 4. Budget
**What to capture:** The Budget page showing the spending-health score, 50/30/20 breakdown, and a couple of per-category budget bars. If sample data includes the Trends tab, the month-over-month chart is a strong alternative second angle.

| | Caption |
|---|---|
| EN | Budgets without the data entry |
| ES | Presupuestos sin capturar datos |

## 5. Learn
**What to capture:** The Learn page showing the four scenario games and the Wealth Builder card, ideally mid-game on one scenario (e.g. the market-crash game showing a "10-year impact" result).

| | Caption |
|---|---|
| EN | Learn money by playing |
| ES | Aprende de dinero jugando |

## 6. Privacy / PIN lock
**What to capture:** Either the PIN lock screen at app launch, or the Today dashboard with Privacy Mode on (all amounts blurred). The blurred-amounts version is more visually interesting.

| | Caption |
|---|---|
| EN | Private by design. PIN-locked. |
| ES | Privado por diseño. Con PIN. |

*Why last: it closes the story — after showing everything the app does, reassure them where it all lives.*

## Checklist before uploading
- [ ] Status bar shows 9:41, full battery, strong signal (use a clean simulator status bar)
- [ ] No personal or real financial data visible — sample data only
- [ ] Captions use the exact text above (short enough to read at thumbnail size)
- [ ] Same 6 shots in the same order for EN and ES localizations
- [ ] 6.9" set uploaded to the 6.9" slot, 6.5" set to the 6.5" slot (App Store Connect does not scale between them)
